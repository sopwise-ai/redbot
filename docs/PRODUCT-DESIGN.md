> 主要参照：[magpie](https://usemagpie.ai/)、[Product Hunt](https://www.producthunt.com/)、

## 1 品牌与文案：三层结构

magpie 的做法值得整套照搬——它用三层把「是什么 / 好在哪 / 凭什么信」分开说，每层只干一件事：

| 层        | 作用                         | RedBot                                       |
| --------- | ---------------------------- | -------------------------------------------- |
| L1 标语   | 一眼看出品类                 | **中文精选网站清单**                         |
| L2 副标语 | 说出差异（比静态清单强在哪） | **上网，一站就够了**                         |
| L3 信任行 | 回答「凭什么信你」           | **免费 · 开源 · 无广告 · 无追踪 · 不用注册** |

对照 magpie：`Every agent's model. One place.` → `Free · Open source · Native. For macOS, Windows and Linux.`
它第二层直接给「免费/开源/原生 + 平台」，我们第二层给的是**动作上的差异**，第三层给信任——
因为「清单」这个品类最容易被怀疑成「又一个导航站」，必须先把「有人挑过、分好类、能点开」说清楚。

### 1.1 L3 信任行的三种长度

| 长度 | 文案                                                                                 | 用在哪                |
| ---- | ------------------------------------------------------------------------------------ | --------------------- |
| 短   | 免费、开源、人工精选。                                                               | 徽章、OG 图小字、侧栏 |
| 中   | 免费 · 开源 · 无广告 · 无追踪 · 不用注册                                             | 页脚、README 引用行   |
| 长   | 免费、开源、人工精选。无广告、无跟踪、不用注册，也不需要安装什么——一个浏览器就够了。 | 落地页、分享文案      |

### 1.2 英文对照（OG / README / 国际读者）

- L1：`A curated list of the Chinese web.`
- L2：`Hand-picked, sorted, one click away.`
- L3：`Free, open source, hand-curated. No ads, no tracking, no sign-up.`

### 1.3 文案规则

#### 必须

- 名词优先：「中文精选网站清单」不是句子，是标签——标签才像品类。
- 动词具体：「点开」「搜到」「存下」，不用「畅享」「一站式」「赋能」。
- 数字具体：「每类 20 个」优于「精挑细选」；「189 个站」优于「海量」。
- 每条目的说明写**使用时机**，不写公司简介：
  好——`查一家公司的股权和诉讼，先看这里`；坏——`专业的商业信息查询平台`。

#### 禁止

- 感叹号、emoji 堆砌、「海量 / 一站式 / 全网最全」。
- 「导航」「大全」——这两个词会把产品拖回 hao123。
- 在首屏出现两个以上并列的卖点句（用户只会记住一句）。

## 2 设计原则（每条：借谁 / 借什么 / 不借什么）

### 2.1 一屏之内回答「这是什么」

借 **Product Hunt**：首屏就是品类词 + 当天精选，不需要滚动才明白。
不借：它的每日排名机制——我们没有「当天新站」这种供给节奏，硬做会变成假榜单。
落地：首页 H1 就是 L1 标语，副行是 L2，搜索框在第一屏可见。

### 2.2 键盘优先，鼠标可选

借 **Linear**（`⌘K` 命令面板、`/` 聚焦、`↑↓` 选择）与 **Raycast**（一次输入直达动作）。
不借：它们的全局快捷键体系——网页里抢系统快捷键会打架，只做页内键位。
落地：`/` 或 `⌘K` 聚焦搜索，`↑↓` 移动，`Enter` 打开，`Esc` 逐层退出，`g t` 去主题页（可选）。

### 2.3 清单必须有「单位」

借 **Hacker News**（每页 30 条、可预测）与 **Product Hunt**（一天一批）。
不借：无限滚动——清单类产品一旦无限，就失去「看完了」的安全感。
落地：每个主题 ≤ 20 条；每个任务 5–10 条；搜索结果超过 50 条时提示「缩小范围」。

### 2.4 每条都要能回答「什么时候用它」

借 **Nomad List**（每个城市几十个结构化字段）与 **Wirecutter**（「适合谁 / 不适合谁」）。
不借：Nomad List 的字段密度——那是它的产品本体，我们的条目只需要一句话。
落地：条目必备 `desc`（使用时机，≤ 28 字）；S 层另加「替代品是谁」一栏，避免同类重复。

### 2.5 密度是尊重

借 **Hacker News** 与 **Are.na**：信息密度本身就是一种「我很专业」的信号。
不借：卡片化的大留白——一屏只放 6 个站的目录站，用户要找的东西在第三屏之外。
落地：PC 端 1160px 内容区、6 列按钮、12–14px 正文；移动端降到 2 列。

### 2.6 收藏要有容器

借 **Are.na 的 channel** 与 **Raindrop 的 collection**：单个收藏没有意义，容器才有。
不借：社交化（公开频道、关注、点赞）——那是社区产品，不是工具。
落地：「场景包」= 一组站点 + 一个名字（`找素材`、`做周报`），本地保存，可导出 JSON。

### 2.7 信任要可见

借 **Kagi**（「无广告、付费、所以不用讨好广告主」）与 **Stripe**（把定价与限制写在明处）。
不借：付费墙——我们是免费产品，靠「不卖位置」建立信任。
落地：页脚固定三句话（免费开源 / 无跟踪 / 不卖位置），并链到 `SECURITY.md` 与 `LICENSE`。

## 3 信息架构

```text
/                 首页：搜索 + 任务入口 + 今日精选
/topics/          主题索引（17 个）
/topics/<slug>/   主题页（每类 ≤ 20 条）
/search/?q=       全站搜索（可分享、可直达）
/my/              我的：固定的站 / 场景包 / 足迹（三个 tab）
```

- **`/my/` 取代现在的 `/history/`**：足迹只是其中一个 tab，用户对「我的」的心智更强。
- 不做站点详情页。条目的全部信息就是「名字 + 一句话 + 一个链接」，多一页只会稀释点击。
- 站点信息用**悬浮卡**（hover 200ms 后出现，键盘 focus 也可触发），不跳页。

## 4 首页结构（PC 优先）

按首屏高度 900px 计，三段：

### 4.1 第一屏：回答「这是什么」

| 元素       | 规格                                                   | 说明                     |
| ---------- | ------------------------------------------------------ | ------------------------ |
| 品牌行     | 侧栏顶部，logo + RedBot                                | 已有                     |
| H1         | `中文精选网站清单`，28–32px                            | 就是 L1 标语，不用别的词 |
| 副行       | `上网，一站就够了`，15px，muted                        | L2                       |
| 搜索框     | 宽 100%，高 44px，`⌘K` 提示                            | 页面里最大的可交互元素   |
| 任务 chips | 6–8 个：找数据、找素材、找模板、查公司、找工具、找课程 | 点一下进主题/任务页      |
| 信任行     | `免费 · 开源 · 无广告 · 无追踪 · 不用注册` 12px        | L3，第一屏底部           |

设计判断：**搜索框必须在第一屏且最大**。因为「不知道去哪找」的用户，第一动作是描述自己要什么，
而不是浏览分类。分类是给「知道大概方向」的人的第二入口。

### 4.2 第二屏：精选

- 标题：`精选 · 189 个`（数字来自数据，不写死）
- 内容：现有按钮墙，6 列，按主题分段（保留现在的色点分段语言）
- 只放 S 层（人工策展），默认折叠其余

### 4.3 第三屏：主题与页脚

- 17 个主题的网格（emoji + 名称 + 数量），点击进 `/topics/<slug>/`
- 页脚：信任行 + 仓库链接 + 更新日期

## 5 关键页面

### 5.1 搜索页

- 输入即搜（debounce 120ms），结果按「名字命中 > 别名命中 > 说明命中」排序
- 键盘：`↑↓` 选择、`Enter` 打开、`Esc` 回来源页（现有逻辑保留）
- 无结果时给三条建议：换同义词 / 看该主题全部 / 提交这个站
- **搜索要支持拼音首字母**（`zgw` → 中国新闻网）与站点别名（`知乎` → 知乎热榜）

### 5.2 我的

三个 tab，全部本地存储，未登录完整可用：

| tab      | 内容                      | 操作                       |
| -------- | ------------------------- | -------------------------- |
| 固定的站 | 用户手动 pin 的站，可分组 | 拖拽排序、改分组、备注     |
| 场景包   | 「找素材」这类站点集合    | 新建、重命名、导出 JSON    |
| 足迹     | 点过的站，按最近使用      | 单条删除、清空（两步确认） |

### 5.3 悬浮卡

- 触发：hover 200ms 或键盘 focus
- 内容：名称、完整 URL 域名、一句话说明、所在主题、「固定」按钮
- 边界：贴边自动翻转；移动端不触发（改为长按）

## 7 视觉语言

- **颜色**：沿用现有 token。红只用于「当前项 / hover 强调」，不装饰计数与徽章。
- **字阶**：11 / 12 / 13 / 14 / 15 / 18 / 22 / 28 / 32，不写任意值。
- **密度**：PC 6 列、行高 36px、段间距 32px；移动 2 列。
- **暗色**：色点单独走 `dark:`（L=0.75），不复用浅色明度。
- **动效**：分类切换用 View Transitions；尊重 `prefers-reduced-motion`；不做位移，只做透明度与背景。

## 8 状态矩阵

| 状态         | 表现                                           |
| ------------ | ---------------------------------------------- |
| 搜索无结果   | 一句话 + 三条出口（换词 / 看主题 / 提交）      |
| 数据为空分类 | 「这一类还没收录，来提第一个」+ Issue 链接     |
| 长站名       | `truncate` + `title`，不换行、不缩小字号       |
| 慢网         | 骨架屏（`Skeleton`），不转圈                   |
| 离线         | 静态站天然可用；搜索索引已在页面内，不依赖网络 |
| 移动端       | 侧栏转 Sheet；悬浮卡改长按                     |

## 9 可访问性与性能

- 对比度 ≥ 4.5:1；焦点环统一 `ring-ring/30`；skip link 按需挂载（现有实现保留）。
- 语义：`<main id="content">`、`h1` 每页唯一、搜索结果 `aria-live="polite"`（已有）。
- 预算：首屏 JS ≤ 120KB gzip、LCP ≤ 1.2s、无外部字体、无第三方脚本。
- 构建期把全部条目渲染进 HTML（现有 CI 有断言，保留）。

## 10 度量

| 指标                  | 采集方式                       | 说明                             |
| --------------------- | ------------------------------ | -------------------------------- |
| 搜索成功率            | 本地记录「输入后是否点击结果」 | 不上传；需要汇总时由用户主动导出 |
| 人均固定站点数        | 本地统计                       | 「我的」是否有人用，看这个       |
| 7 日回访              | 可选匿名统计                   | 需要你拍板（见战略稿 Q4）        |
| 死链率 / S 层首页占比 | CI 产出                        | 不需要用户数据                   |
