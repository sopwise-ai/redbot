## 4. 已知质量欠账

- **新闻分类仍有门户重叠**：腾讯新闻 / 网易新闻 / 凤凰新闻 / 环球网 四者信息形态相近。17 条已接近配额上限，下一轮建议砍 2 个，名额换给更有辨识度的源。
- **164 条仍指向站点首页**：新闻门户的首页本身就是信息流，可接受；但社区、开发、游戏类应尽量指向榜单或列表页。`npm run validate` 会打印数量。
- **副标签有 50 个**：随目录增长而膨胀，下一轮应按分类收敛到每类 ≤5 个。
