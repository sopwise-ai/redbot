# Linear 方向重做（2026-11-04）

> 取代 [2026-11-04-home-hero-design.md](./2026-11-04-home-hero-design.md)。上一版「暖纸 + 衬线」被否，改为 Linear 那一路。

## 决策

**深色优先 + 全无衬线 + 8px 圆角 + 无阴影 + 单一红色强调。**

- 画布：深色近黑 `oklch(0.145 0.004 264)`，面板 `card 0.185` / `sidebar 0.165`，靠 8% 白线分层。
  浅色是冷白 `0.985` + 纯白卡片；不再使用暖黄/米色。
- 字体：只有 `--font-sans`（+ 代码用的 `--font-mono`）。标题也用 sans，weight 600、`tracking-[-0.02em]`。
  **删掉 `--font-serif` 与全部 `font-serif` 用法。**
- 标题：H1 36 / 60 / 72；首页主题 h2 18（600）；卡片标题 14；元信息 12。
- 圆角：`--radius: 0.5rem`；卡片、按钮、搜索框统一 8px；只有筛选 chip 与状态点保留 pill。
- 阴影：默认不用；只有 Popover / Dialog / 浮层用 `shadow-lg`。
- 筛选 chip：选中态用前景/背景黑白反转（dark 白底黑字 / light 黑底白字），不用品牌红。
- 首屏：标题后方一层极淡红晕（深色 0.16 / 浅色 0.06），不加渐变网格、不加产品截图。
- 默认主题：`dark`（仍可在三态切换里选浅色/跟随系统）。

## 不做什么

- 不引入第三方字体、不改 `src/components/ui/`。
- 不把按钮墙改成产品截图：按钮墙本身就是产品，下一屏就是它。
- 不为了「像 Linear」而加假 UI 面板或装饰性网格。

## 验收

- 1440 / 390、深色 / 浅色截图；暗色下文字对比度仍过 `contrast.test.ts`。
- `npm run verify`、`npm run build` 通过；README 首屏图同步为深色默认态。
