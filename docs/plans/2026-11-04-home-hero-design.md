# 首页 Hero 重设计（2026-11-04）

## 问题

现状是「白画布上再套一张圆角卡」：粉色径向渐变、30px 衬线标题、五个对勾、右侧三块统计数字。

1. 渐变 + 卡片是模板站的做法，和下方按钮墙抢视觉。
2. 标题 30px 放在 1160px 容器里撑不住，右半屏只能靠统计数字填空。
3. 主按钮是「按主题浏览」，但产品灵魂是「点一下就走」，主次反了。
4. 五个对勾把首屏变成 feature list，可信感没增加，噪音满了。

## 参考

- **Linear**（首屏）：72px 两行大标题 / 16px 一行副标，没有按钮，右侧只挂一个低调链接；下半屏是真实产品界面。可量化的点是**字号对比接近 5:1**。
- **Are.na**（首屏）：680px 窄栏、四周留白，用 a/b/c 三条列表解释「Are.na 是什么」，两个按钮；整屏没有任何装饰元素。
  **对 RedBot 最有用**：卖的是清单，首屏就该长成清单，而不是仪表盘。

> Vercel / Raycast / GitHub / 少数派 / Basecamp 在无头环境加载超时或白屏，未作为依据。

## 决策：编辑部刊头（A′）

保留红点品牌资产，**暖白纸色 + 放大排印 + 抬高标题层**：

- 删除：卡片外壳、径向渐变、徽章、「189/17/日期」大数字块、五个对勾。
- 标题：衬线 72px（lg）/ 60px（sm）/ 36px（mobile），weight 400，8 个字一行。
- 纸色：主画布 `oklch(0.985 0.004 80)`、卡片纯白、边框暖灰；深色同样偏暖。
- 标题层：H1 与首页主题 h2 都用衬线（weight 400 + 0.01em 字距），形成双声部，而不是只有 H1 一个例外。
- 眉标：`人工挑选 · 189 个信息源`，12px、字距 0.14em。
- 副标：`上网，一站就够了。` 18–20px + 14px 行为说明。
- 刊头行：左侧眉标、右侧更新日期，两端对齐。
- 动作：主 `随机一个`（红胶囊，h-11），次 `按主题浏览`（ghost，低调）。
- 信任：一行 12px 灰字，无图标。
- 信任：一行 12px 灰字，无图标。
- **不做主题目录行**：左侧栏已经是导航，hero 里再列一遍 17 个主题只会重复。首屏到信任行为止。

## 规格

| 元素     | 规格                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 容器     | 1160px（沿用），无卡片、无阴影                                                 |
| H1       | `font-serif`，`text-4xl sm:text-6xl lg:text-7xl`，weight 400，`leading-[1.06]` |
| 眉标     | `text-xs tracking-[0.14em] text-muted-foreground`                              |
| 副标     | `text-lg sm:text-xl`，下方解释句 `text-sm`                                     |
| 主按钮   | `size="lg"` + `h-11 rounded-full`，`bg-primary`                                |
| 次动作   | ghost + `ArrowRight`，hover 时箭头右移 2px（`motion-reduce:transform-none`）   |
| 纵向节奏 | hero 顶部 `pt-10 sm:pt-14`，信任行后 `gap-12` 直接进第一个主题区块             |

## 非目标

- 不做渐变 / 光晕 / 插画 / 产品截图：白画布 + 红点是品牌，这些元素会把它变成模板站。
- 不在 hero 里再放一个搜索框：顶栏已经有一个。
- 不做主题目录行：左侧栏已经是导航。
- 不新增 CTA：仍然只有「随机一个」和「按主题浏览」。

## 响应式 / 无障碍

- 390px：H1 36px 仍是一行；动作换行；信任行折行。
- 没有目录行以后，首屏高度更短：390×844 下能看到第一个主题的前两条。
- 深浅色同结构，只用 `--border` / `--muted-foreground` 等 token。
- 标题用 `<h1 id="hero-title">`，section 用 `aria-labelledby`。
- 无自动播放动画；`prefers-reduced-motion` 下箭头不做位移。
